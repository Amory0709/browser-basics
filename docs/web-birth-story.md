# Web 诞生：CERN 的困境与 Tim 的答案

> 故事版总结。时代脉络见 [frontend-eras-summary.md](frontend-eras-summary.md)。

---

## 背景：一座永远在施工的城市

1989 年，瑞士日内瓦，CERN（欧洲核子研究中心）。

几千名科学家来自不同国家，使用不同的计算机系统—— Unix 终端、VMS 机器、Mac、IBM VM/CMS。他们在设计粒子加速器、编写分析代码、运行实验。文档、代码、讨论、人事信息散落在多个系统里。

走廊里经常有人拦住同事问：「那个模块是谁写的？文档在哪里？」

常见的回答是：「去问 Pierre—— 哦，他上个月已经离开了。」

---

## 困难：知识在，但找不到

CERN 并不缺少记录。实验笔记在文件系统里，正式报告登记在 CERNDOC 里，讨论发在 Usenet News 组里，谁负责什么靠老员工口口相传。

Tim Berners-Lee 看到的核心矛盾是：

> 组织的真实结构是一张**网**—— 人连接项目，项目连接模块，模块连接文档。  
> 信息的存储方式却是一棵棵**树**—— 文件夹、分类号、HELP 命令链，每样东西只能有一个「父节点」。

### 树装不下真实世界

查 VMS 的 HELP 系统，你沿着命令链一路点下去：

```
HELP COMPILER SOURCE_FORMAT PRAGMAS DEFAULTS
```

到了叶子节点，却看到一句：「请去看 HELP COMPILER COMMAND OPTIONS DEFAULTS PRAGMAS。」

明明只是一次跳转，你却必须**退出系统、重新输入另一条命令链**。Tim 认为：这里需要的不是新路径，而是一个**链接**—— 点一下，跳过去。

### 信息随人流失

CERN 项目持续变化，纸质手册印完就过时。电子文档其实写了不少，但分散在六七个互不连通的系统里—— **不是没记录，是找不到**。

员工平均停留约两年。人走了，关联就断了。新人只能从走廊八卦重新开始。

---

## 伏笔：Enquire

1980 年，Tim 在 CERN 控制室写过程序 **Enquire**。

它不建文件夹树，而是建**圆圈和箭头**—— 一个圈可以代表一个人、一个模块或一份文档；箭头表示「依赖」「包含」「谁写的」。找信息像玩文字冒险游戏：从一个节点出发，沿链接走到下一个。

Enquire 很有用，但只是**个人笔记本**，跑在一台机器上，无法跨网络，也无法成为全 CERN 的基础设施。

1989 年 Tim 回到 CERN，同样的问题还在，而且更大—— LHC 时代即将到来，项目规模还要再涨一个量级。

---

## 顿悟：不造新孤岛，造「通用跳转层」

Tim 没有提议「再做一个文档系统，把所有人数据搬进来」—— 那永远搬不完，各组也不会配合。

他的思路是：

1. **旧系统继续各管各的**（CERNDOC、文件系统、News、电话簿……）
2. 在上面加一层 **Gateway**，把旧数据**映射成可跳转的超文本视图**
3. 用统一的 **Browser** 浏览，用 **URL** 寻址，用 **HTTP** 传输，用 **HTML** 写链接

不是推倒重来，而是**给已有的信息世界装上门和路标**。

1989 年提案里，这套系统还叫 **「Mesh」**（网）。1990 年写代码时，Tim 把它命名为 **World Wide Web**。

---

## 第一束光：1990 年 12 月

在 NeXT 工作站上，Tim 完成了：

- 第一个浏览器 **WorldWideWeb**（能浏览，也能编辑）
- 第一个 Web 服务器
- 第一批 HTML 页面
- 第一次 HTTP client-server 通信

没有 CSS，没有 JavaScript，没有 Google。只有**纯文本和链接**。

但魔法在于：你在 Unix 终端上点一个链接，可以跳到 CERN 另一台机器上的文档—— 或通过 Gateway 看到 CERNDOC 里登记的内容。复杂的路径、命令、分类号，被压缩成一个**可分享、可收藏、可转发**的地址。

---

## 为什么后来扩散到全世界

Tim 在 CERN 要解决的，是**复杂组织里信息如何不被时间和人员流动吞噬**。他给出的答案不是更厚的手册，而是：

> **让信息像城市街道一样连在一起—— 你站在任意路口，都能走到该去的地方。**

三个关键决定让 Web 走出实验室：

| 决定 | 意义 |
|------|------|
| **链接是核心** | 先解决「找到并跳过去」，而不是先做漂亮排版 |
| **Client/Server 分离** | 存储和展示分开，各平台只需实现 Browser |
| **1993 免版税** | CERN 宣布 Web 协议和代码免费，Mosaic 浏览器兴起，Web 冲向全球 |

---

## 困难与解法对照

| 困难 | Web 的解法 |
|------|-----------|
| 知识随人离开而消失 | URL 永久指向资源 |
| 各系统各自为政 | Gateway 映射，不强制搬库 |
| 树形结构装不下网状现实 | Hypertext 自由链接 |
| 平台太多（Unix/VMS/Mac/终端） | HTTP + 统一 Browser 接口 |
| 新人不知道找谁、找哪 | 从任意节点浏览，不必先知道路径 |
